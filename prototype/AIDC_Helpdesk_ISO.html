เปิด Ticket ใหม่

แบบฟอร์มรับแจ้งเหตุขัดข้องและคำร้องขอบริการ ตามกระบวนการ Incident / Service Request / Change Management กรุณากรอกข้อมูลให้ครบถ้วน ระบบจะคำนวณระดับความสำคัญและกำหนดเวลาตาม SLA ให้อัตโนมัติ

ข้อมูลที่กรอกจะถูกบันทึกเป็นหลักฐานตามระบบบริหารคุณภาพ ทุกฟิลด์ในแบบฟอร์มนี้ถูกจัดเก็บเป็นสารสนเทศเอกสาร (Documented Information) ตาม ISO/IEC 20000-1:2018 ข้อ 7.5 และสอบกลับได้ตาม ISO 9001:2015 ข้อ 8.5.2

      การปฏิบัติตามมาตรฐานและการอนุมัติ

      ISO/IEC 27001:2022 A.5.12 / A.5.24 / A.5.34
      ระดับชั้นความลับข้อมูล (Data Classification) *

      บังคับกรอกสำหรับ Service Request และ Change Request — Ticket จะอยู่ในสถานะ Pending Approval จนกว่าผู้อนุมัติจะพิจารณา

      ข้อกำหนดบังคับของกระบวนการบริหารการเปลี่ยนแปลง ตาม ISO/IEC 20000-1 ข้อ 8.5.1
      มีข้อมูลส่วนบุคคลเกี่ยวข้องกับเรื่องที่แจ้ง เช่น รายชื่อพนักงาน เลขบัตรประชาชน ข้อมูลเงินเดือน ภาพถ่ายบุคคล หรือข้อมูลลูกค้า
      ต้องบันทึกความยินยอมก่อนดำเนินการ เจ้าหน้าที่จะเข้าถึงข้อมูลส่วนบุคคลเท่าที่จำเป็นต่อการแก้ไขปัญหาเท่านั้น และมีการบันทึกการเข้าถึงทุกครั้ง

      เกี่ยวข้องกับเหตุการณ์ความปลอดภัยสารสนเทศ (Information Security Event) เช่น สงสัยว่าถูกเจาะระบบ มัลแวร์/แรนซัมแวร์ อีเมลหลอกลวง ข้อมูลรั่วไหล หรือบัญชีผู้ใช้ถูกใช้งานผิดปกติ
      Ticket นี้จะถูกส่งต่อให้ Head of IT และทีม Information Security ทันทีเมื่อกดส่ง ระบบจะแจ้งเตือนคู่ขนานทางอีเมลและ SMS ตามขั้นตอนรับมือเหตุการณ์ความมั่นคงปลอดภัย ISO/IEC 27001:2022 Annex A ข้อ A.5.24 กรุณาอย่าปิดเครื่องหรือลบไฟล์ใด ๆ จนกว่าเจ้าหน้าที่จะติดต่อกลับ เพื่อรักษาหลักฐานดิจิทัล
      เมื่อกดส่ง ระบบจะออกรหัส Ticket เริ่มจับเวลา SLA และสร้างรายการแรกใน audit trail ทันที
